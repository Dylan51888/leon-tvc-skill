# leon-tvc-skill

把产品主视觉 + 分镜表变成一支可交付的 15 秒商业 TVC。

## 安装

在豆包对话框里发送：

```
帮我安装这个 Skill：https://github.com/Dylan51888/leon-tvc-skill
```

## 用法

准备好产品主视觉和分镜表，然后说：

```
用 leon-tvc-skill 出片
```

它会先给你一份完整的参数确认清单，你确认后才开始生成。

## 它帮你做什么

- 按分镜表逐镜生成，并校验总时长
- 自动带上产品一致性约束（比例、纹样、文字、色温）
- 自动排除人物、手、水印、知名 IP
- 生成前列出完整参数确认清单
- 结尾自动保留产品定格 3 秒
- 出片后给出画面 / 分镜 / 配乐三项自检结果

## 说明

AI 给的是初版。真要交付客户，画面、分镜、配乐还得人工再仔细校准一遍。
